Pilote Logo 3D Studio avec un agent IA

Un agent (Claude Code, Codex, Hermes, OpenCode, ou l’agent intégré au navigateur) peut importer un logo SVG, régler la 3D et exporter image, vidéo ou objet 3D, sans cliquer dans l’interface. Tout se passe dans la page : window.BinksyAPI et, si le navigateur le permet, des outils WebMCP.

1Ce que l’agent peut faire

Chaque outil WebMCP correspond à une méthode de window.BinksyAPI (entre parenthèses).

  • logo3d_describeDécrit l’app et la liste des outils (describe()).
  • logo3d_etatRésumé de l’état : logo, look, forme, matière, lumière, fond, animation, cadre (getState()).
  • logo3d_importerImporte un SVG (le logo 3D), une image PNG/JPEG/WebP posée sur le logo, ou un projet .logo3d.json (importer()).
  • logo3d_exporterExporte en PNG, JPEG, MP4, WebM, GIF, séquence PNG, GLB, GLTF, OBJ, STL, USDZ, visionneuse HTML, kit ZIP ou projet ; renvoie les fichiers en base64 (exporter()).
  • logo3d_lister_optionsCatalogues : looks, matériaux, lumières, fonds, animations, profils, biseaux, cadres, vues (listerOptions()).
  • logo3d_lister_looksListe les looks prêts à l’emploi, par catégorie (listerLooks()).
  • logo3d_appliquer_lookApplique un look complet par son id (appliquerLook()).
  • logo3d_formeÉpaisseur, profil, intensité, biseau, qualité du maillage (setForme()).
  • logo3d_materiauMatière : preset, couleur, métal, rugosité, verre, vernis, lueur (setMateriau()).
  • logo3d_lumiereLumière : preset, exposition, rotation, ombre, tonalité (setLumiere()).
  • logo3d_fondFond : preset, transparent, couleur ou dégradé, sol, reflet (setFond()).
  • logo3d_animationAnimation de la boucle, durée, intensité, courbe, lecture (setAnimation()).
  • logo3d_cadreCadre (libre, 1:1, 16:9, 9:16, 4:5) et vue de caméra (setCadre()).
  • logo3d_set_paramRéglage avancé par chemin, ex. post.bloom, mat.cur.iridescence (setParam()).
  • logo3d_annulerAnnule la dernière modification, comme le bouton de l’app (annuler()).
  • logo3d_retablirRétablit la modification annulée (retablir()).
  • logo3d_resetRevient au logo de démo et au look par défaut (annulable) ; demande l’accord de l’utilisateur (reset({confirm:true})).

2Connexion A : agent dans le navigateur (WebMCP)

Ouvre logo3d.binksdesign.com dans un Chrome récent où WebMCP est disponible. WebMCP est encore expérimental : selon la version, il faut activer le flag d’aperçu WebMCP dans chrome://flags (cherche « WebMCP ») ou passer par une extension compatible (par exemple MCP-B). Les noms de flags changent d’une version à l’autre : vérifie la documentation Chrome for Developers.

Au chargement, l’app enregistre ses outils logo3d_* via document.modelContext.registerTool() (ou l’ancienne forme navigator.modelContext). L’agent du navigateur les voit apparaître tout seul. Sans WebMCP, rien ne change : l’app fonctionne normalement.

3Connexion B : Claude Code, Codex, Hermes, OpenCode

Ces agents pilotent un navigateur local grâce à un serveur MCP standard, Playwright MCP. Ajoute-le à la configuration MCP de ton agent :

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Consigne pour l’agent : ouvrir l’URL de l’app (browser_navigate), puis appeler window.BinksyAPI avec l’outil d’évaluation JavaScript (browser_evaluate). Toutes les méthodes sont asynchrones et renvoient du JSON.

Découvrir les outils

await BinksyAPI.ready();
const info = await BinksyAPI.describe();      // { app, version, apiVersion: "1", tools: [...] }
const options = await BinksyAPI.listerOptions(); // ids des looks, matériaux, lumières…

Importer un logo SVG

// SVG fourni par l’utilisateur, en texte ou en base64
await BinksyAPI.importer({ files: [{ name: "logo-client.svg", type: "image/svg+xml", dataBase64: "PHN2ZyB4bWxucz0i..." }] });
await BinksyAPI.appliquerLook({ id: "forge" });
await BinksyAPI.setForme({ epaisseur: 0.4, biseau: "round" });
await BinksyAPI.setCadre({ ratio: "1:1" });

Exporter

const png = await BinksyAPI.exporter({ format: "png", size: 2160, transparent: true });
// png.files[0] = { name: "logo-client-3d.png", type: "image/png", size, dataBase64 }
await BinksyAPI.setAnimation({ type: "rotY", duree: 6 });
const mp4 = await BinksyAPI.exporter({ format: "mp4", size: 1080, fps: 30 });
const glb = await BinksyAPI.exporter({ format: "glb", widthMm: 100 });
// download: true déclenche aussi le téléchargement dans le navigateur

Les erreurs sont renvoyées sous la forme { code, message } en français, par exemple { code: "LOOK_INCONNU", message: "…" }. Les vidéos et le moteur photoréaliste peuvent prendre plusieurs minutes.

4Prompt prêt à copier

Ouvre https://logo3d.binksdesign.com/ avec le navigateur (Playwright MCP) et utilise uniquement window.BinksyAPI via browser_evaluate.
1. await BinksyAPI.ready(), puis BinksyAPI.describe() pour lire les outils.
2. Importe mon logo SVG (fichier que je te fournis) avec BinksyAPI.importer.
3. Choisis un look adapté avec listerLooks / appliquerLook, puis ajuste setForme, setMateriau, setLumiere, setFond si besoin.
4. Exporte un PNG 2160 px fond transparent et un MP4 1080 d’une rotation (setAnimation type "rotY") avec BinksyAPI.exporter, et enregistre les fichiers renvoyés en base64.
N’invente aucun logo, couleur ou nom de client : utilise seulement ce que je fournis.

5Rien n’est envoyé

L’API tourne entièrement dans la page : pas de serveur, pas de compte, pas de clé API. Le logo et les exports restent dans ton navigateur (enregistrement automatique local, IndexedDB et stockage de session). L’agent ne fait que ce que tu lui demandes, avec les fichiers que tu lui donnes.

In English

Logo 3D Studio exposes window.BinksyAPI (async, JSON in/out) and, when the browser supports it, WebMCP tools named logo3d_*. In-browser agents see the tools automatically. Coding agents (Claude Code, Codex, Hermes, OpenCode) can use Playwright MCP (npx @playwright/mcp@latest): open the app URL, then call await BinksyAPI.describe(), BinksyAPI.importer({files:[{name:"logo.svg",dataBase64}]}) and BinksyAPI.exporter({format:"png"}) through browser_evaluate. Everything stays local: no server, no account, no API key.
